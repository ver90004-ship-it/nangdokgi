# 낭독기

붙여넣은 글을 브라우저 내장 음성으로 끝까지 읽어주는 한 장짜리 웹페이지. 공부할 때 교재·필기·논문을 귀로 듣기 위해 만들었다.

의존성도 빌드도 없다. `index.html` 하나가 전부이고, 서버 없이 파일을 더블클릭해도 그대로 동작한다.

## 기능

- **길이 제한 없음** — 문장 단위로 쪼개 엔진 큐에 미리 넣는 방식이라 1만 자, 2만 자도 정지를 누를 때까지 끊기지 않는다. 엔진이 조용히 멈추면 감시 타이머가 읽던 자리에서 되살린다.
- **읽는 위치 표시** — 현재 문장에 배경과 세로줄 표시, 지난 문장은 흐려진다. 문장을 누르면 그 자리부터 다시 읽는다.
- **따라가기 토글** — 켜 둔 동안만 화면이 읽는 곳을 쫓아간다. 꺼 두면 스크롤을 건드리지 않는다.
- **마크다운을 서식으로** — `#`, `*`, `-`, `>`, `` ` `` 같은 기호는 화면에도 남기지 않고 소리로도 내보내지 않는다. 제목·굵게·목록·인용으로만 적용한다. 대시(`-`)와 플러스(`+`)는 발음에서 제외.
- **문단 유지** — 원문에 빈 줄이 있던 자리만 한 줄 띄우고, 한 문단 안에서는 줄을 이어 붙여 한 흐름으로 읽는다.
- **대기열 + 폴더** — 여러 글을 쌓아 두고 폴더로 묶어 골라 읽는다. 제목·폴더 검색, 폴더 접기/펼치기.
- **북마크** — 문장 단위로 표시해 두고 목록에서 바로 그 자리로 건너뛴다.
- **음성 설정** — 목소리 선택, 속도(0.5~3배), 음량, 음높이, 문장 사이 쉼, 글자 크기, 반복 읽기.
- **내보내기 / 가져오기** — 대기열 전체를 JSON 파일로 저장하고 다시 불러온다.
- 야간 모드, 단축키(`Space` 재생·일시정지, `←` `→` 문장 이동, `B` 북마크, `Esc` 정지).

## 호스팅

현재 Cloudflare Workers로 서비스 중: https://nangdokgi.darkarea.workers.dev/

`index.html` 하나만 서빙하면 전부 동작한다. 폰에서 홈 화면에 추가하면 앱처럼 쓸 수 있고, 아이콘과 앱 이름은 페이지 안에 들어 있어 따로 파일이 필요 없다.

오프라인에서도 열리게 하려면 워커가 `/sw.js` 경로로 이 저장소의 `sw.js`를 함께 내보내면 된다. 페이지는 HTTPS일 때만 서비스워커를 등록하고, 없으면 조용히 넘어간다.

## 깃허브 페이지로 띄우기

```bash
gh auth login                                   # 한 번만
gh repo create nangdokgi --public --source=. --push
gh api --method POST /repos/{owner}/nangdokgi/pages \
  -f "source[branch]=main" -f "source[path]=/"
```

1~2분 뒤 `https://{owner}.github.io/nangdokgi/` 에서 열린다. `{owner}` 자리에는 깃허브 아이디를 넣는다.

CLI 없이 하려면 깃허브에서 새 리포지토리를 만들어 이 폴더를 올린 뒤, Settings → Pages → Source를 `main` 브랜치 루트로 지정하면 된다.

## 저장되는 곳

대기열·북마크·설정은 브라우저 안에 저장된다. IndexedDB가 주 저장소이고 `localStorage`를 보조로 함께 쓴다. localStorage만 쓰면 5MB 근처에서 조용히 실패해 다음에 열 때 대기열이 사라지기 때문이다. 저장 상태는 대기열 아래에 시각·글 수·저장 위치로 표시되고, 실패하면 경고가 뜬다.

`navigator.storage.persist()`로 영구 저장을 요청하므로 브라우저가 공간을 되찾을 때도 지워지지 않는다. 새로고침·브라우저 재시작·기기 재부팅 모두 유지된다.

**주소마다 따로 저장된다.** `file://`로 열던 내용은 `workers.dev` 주소로 따라오지 않는다. 옮기는 방법은 두 가지다.

- **내보내기 / 가져오기** — JSON 파일로 받아서 다른 쪽에서 불러온다.
- **폰으로 옮기기** — 대기열 전체를 글자 코드로 꺼내 복사한 뒤, 폰에서 붙여넣고 가져오기를 누른다. 파일을 주고받기 번거로운 모바일용.

## 요구 사항

Web Speech API를 지원하는 브라우저. 크롬·엣지에서 가장 안정적이다. 한국어 음성이 없으면 Windows 설정 → 시간 및 언어 → 음성에서 추가한다. 음성 합성은 브라우저가 처리하므로 페이지를 한 번 받고 나면 인터넷 없이도 읽는다.
